# 1편: 머슴아, 국밥집 찾아 와라

주인님이 조금씩 말씀하시는 걸 머슴이 여기 모아 두었다가, 다 모이면 촬영 순서와 대본으로 정리합니다.

## 주인님이 말씀하신 것 (모으는 중)
- (아직 없음)

## 정할 것
- 어느 동네, 어떤 국밥 (순대국, 돼지국밥, 소머리국밥 등)
- 언제 찍을지 (쉬는 날)
- 혼자 갈지, 누구랑 갈지
- 티격태격 장면 1~2개
- 맛 평가와 머슴 점수 매기는 방식

## 촬영 순서 (다 모이면 정리)
1. 시작: 캐릭터 그림 + 제목
2. 시키기: "머슴아, 국밥집 찾아 와라" (휴대폰 화면)
3. 해 보기: 가서 먹기 (1인칭)
4. 평가: 맛 평가 + "오늘 머슴 몇 점"
